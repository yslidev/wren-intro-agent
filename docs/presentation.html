What we built

Core

  • iMessage agent, no app
  • Resume or JD first, then stories
  • Approved blurb + role card
  • Double opt-in, privately
  • Anonymous till yes
  • Ditto-style group intro
  • Respond / react / ignore
  • Private follow-up

Matching + voice

  • Role, pay, setup filters
  • 2+ shared skills, scored
  • A reason for every point
  • One match at a time
  • Matchmaker-friend voice
  • Feelings first (EQ)
  • Rewords awkward questions

World + infra

  • 42 companies, 150 people
  • 6 recruiter voices
  • Claude Haiku 5.5 + rules
  • Spectrum, Linq, Mac kit, sim
  • Never texts fake numbers
  • 3 one-click demos
  • Pages, Render, CI

What we changed

From live testing

  • Opus → Haiku 5.5, EQ prompt
  • No “why leave?” after a layoff
  • Smart quotes (“I’m”) fixed
  • Greetings aren't names
  • Grammar pass
  • Secret guard on .env.example

From review

  • Candidate name hidden till yes
  • Stricter matching
  • Fictional people never texted
  • Employer path + resume step
  • Ditto-style group intro
  • Web prototype → iMessage agent
